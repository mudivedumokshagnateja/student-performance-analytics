# 🎓 Student Performance Analytics

## 📌 Project Overview

This project analyzes student academic performance using Python and Data Analytics techniques. It explores how various factors such as study time, attendance, parental education, and other attributes influence students' exam scores. The project also includes data visualization and machine learning to gain insights and predict performance.

---

## 📂 Dataset

The dataset contains student-related information, including:

- Study Hours
- Attendance
- Previous Scores
- Parental Education
- Internet Access
- Extra Activities
- Final Exam Score

> **Dataset File:** `data/student_performance_raw.csv`

---

## 🎯 Objectives

- Perform Exploratory Data Analysis (EDA)
- Clean and preprocess the dataset
- Visualize relationships between features
- Build a predictive machine learning model
- Evaluate model performance

## 🚀 How to Run

1. Clone the repository

```bash

```

2. Navigate to the project folder

```bash
cd student-performance-analytics
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Launch Jupyter Notebook

```bash
jupyter notebook
```

5. Open:

```
notebooks/student_performance_analytics.ipynb
```
